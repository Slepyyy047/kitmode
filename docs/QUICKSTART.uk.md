# Швидкий запуск KitMode

Для роботи потрібні Python 3.12+, доступ до інтернету й токен Telegram-бота. На Windows додатково встановлюється `tzdata` разом із залежностями проєкту, щоб Python знаходив часові пояси.

## 1. Створи середовище Python

Відкрий термінал у папці клонованого репозиторію `kitmode`.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

Linux/macOS:

```sh
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -e '.[dev]'
```

Перед запуском переконайся, що команда `python --version` показує Python 3.12 або новішу версію.

## 2. Перевір локальний запуск

На Windows можна скористатися `run.ps1`: він шукає справний Python у `.venv`, у
системі або в локальному середовищі Codex. Самостійно пакети не встановлює. У
поточному середовищі перевірено команди:

```powershell
.\run.ps1 -Mode check
.\run.ps1 -Mode demo
# Після збереження токена у .env:
.\run.ps1 -Mode run
```

Якщо PowerShell блокує запуск скрипта, запусти його одноразово так:
`powershell -ExecutionPolicy Bypass -File .\run.ps1 -Mode demo`. Це не змінює
постійні налаштування системи. Для звичайного окремого встановлення Python
використовуй модульні команди:

```sh
python -m kitmode check
python -m kitmode demo
```

Команда `demo` використовує симулятор Telegram і не надсилає повідомлень у мережу.
Щоб запустити бота з реальним Telegram-з’єднанням, створи бота через BotFather,
збережи його секретний токен локально та виконай checklist перед запрошенням
користувачів. Не додавай токен до Git або публічних журналів. Цей комплект не
перевіряв live-з’єднання: токена для тесту не надано.

Переконайся, що обраний username доступний у Telegram. KitMode не резервує ім’я та не гарантує, що воно вільне.

## 3. Налаштуй локальну конфігурацію

Створи файл `.env` у папці `outputs/kitmode`:

```dotenv
TELEGRAM_BOT_TOKEN=встав_токен_від_BotFather
KITMODE_DB=data/kitmode.sqlite3
ADMIN_IDS=
AI_ENABLED=false
AI_SPENDING_APPROVED=false
OPENAI_API_KEY=
OPENAI_MODEL=
AI_DAILY_LIMIT=3
```

Перед запуском заповни `TELEGRAM_BOT_TOKEN`. `ADMIN_IDS` — необов’язковий список Telegram user ID, розділений комами. Не вказуй там чужі облікові записи.

Функції AI вимкнені за замовчуванням. Їх увімкнення може спричинити оплату провайдеру: потрібні окреме погодження витрат оператором (`AI_SPENDING_APPROVED=true`), налаштування ключа й моделі та згода самого користувача в боті. Не роби платних запитів для перевірки.

## 4. Запусти бота

```sh
python -m kitmode run
```

Відкрий приватний чат із ботом у Telegram і надішли `/start`. `/help` показує довідку; `/today`, `/habits`, `/progress`, `/friends` і `/settings` відкривають відповідні розділи.

Локальні нагадування надсилаються, лише коли комп’ютер увімкнений, є інтернет і
процес `run` працює. Після зупинки процесу нагадування не надсилатимуться.
Автоматичного хостингу немає. Для @kitmode_bot перевірено підключення та локальний
запуск. Реальне доставлення нагадувань і вигляд екранів у клієнті перевіряються окремо.

## Користування

Місто й час сну обираються кнопками. Створення звички: назва → тип → кількість
(за потреби) → розклад → нагадування → перегляд і збереження. Готові звички
можна відкрити одразу без введення назви. Мінімум, дати, перевірка й додатковий
опис доступні в «Додаткових параметрах». Власне значення — необов’язковий вибір.

«Сьогодні» показує лише заплановані звички. Натисни назву для дій або
«Виконано все» для звички-дії. Ліміт вимагає явного загального результату,
зокрема нуля; кількісна звичка додає результат. Історія, редагування, пауза
та архів — у «Більше». `/start` відкриває меню; незавершений діалог
можна продовжити окремою кнопкою. Старі кнопки попередньої версії
більше не працюють, але історія й налаштування залишаються.

## Дані й резервні копії

База за замовчуванням лежить у `data/kitmode.sqlite3`. Це звичайний локальний SQLite-файл; доступ до нього обмежуй засобами облікового запису й диска операційної системи. Експорт робиться в меню налаштувань. Резервні копії зберігай у захищеному місці та видаляй вручну не пізніше ніж через 7 днів.

Видалення профілю очищає локальні дані KitMode, але не стирає історію чату Telegram, копії на сторонніх пристроях або резервні копії оператора.

Що перевірено локально та що ще не пройшло живу перевірку — дивись у [чеклисті Telegram](LIVE-CHECKLIST.md).

## Аватарка, опис і кнопка меню

Для поточного @kitmode_bot оформлення застосовано. У нижній частині чату Telegram
є кнопка меню команд: почати, меню, додати звичку, сьогодні, мої звички, прогрес,
налаштування, довідка та скасування. `/new` одразу додає звичку, `/menu` повертає
на головний екран. Назва, опис, короткий текст профілю й команди перекладені
українською, російською та англійською.

Для власного бота після налаштування токена: `python -m kitmode profile`. Команда
оновлює публічне оформлення бота з чинного `.env`; звички та записи не змінює.
